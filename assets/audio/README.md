# Geluiden en bronvermelding

De vijf bestanden hieronder staan in deze gedeelde map. De namen zijn kort
gehouden zodat je ze makkelijk in Python kunt gebruiken. De oorspronkelijke
bestandsnamen staan bij de credits, zodat de herkomst terug te vinden is.

Geen van de geluiden is standaard aangesloten in de lesgames. Ze staan klaar
voor uitbreidingen. De bosambiance duurt ongeveer 115
seconden, de grot 31 seconden, de kerker 21 seconden en het vuureffect 8
seconden. Speel het lange vuureffect daarom niet bij ieder snel schot af.

Deze vermelding is gebaseerd op de door de docent opgegeven credits. Houd
dit bestand bij wanneer je een game met deze geluiden deelt.
